# Keitaro Campaigns

Локальная обёртка над [Keitaro Admin API v1](https://admin-api.docs.keitaro.io/). FastAPI, SQLAlchemy, SQLite, HTML и JavaScript.

## Запуск

Требуется Python 3.11 или новее. Один раз скопируйте `.env.example` в `.env`, укажите `KEITARO_API_KEY` из **Профиль → API ключи** и замените `CAMPAIGN_PREFIX` на `test_вашафамилия_` латиницей. Ключ должен иметь доступ к кампаниям, потокам, справочникам и отчётам. Браузер его не получает.

Из папки проекта выполните:

```sh
python3 run.py
```

На Windows можно использовать `py run.py`. Скрипт создаёт окружение, устанавливает зависимости, применяет миграции и запускает сервер. Затем откройте [интерфейс](http://127.0.0.1:8000) или [Swagger](http://127.0.0.1:8000/docs). Если порт занят, запустите `python3 run.py --port 8011`. Для остановки нажмите Ctrl+C.

Для знакомства без ключа запустите `python3 run.py --demo`. Кампании и офферы в этом режиме вымышленные, а изменения пропадают при остановке сервера.

Приложение рассчитано на локальный запуск одним процессом. Для общего размещения нужна аутентификация.

## Как пользоваться

- **Создание.** Выберите оффер, домен, группу и источник из справочников Keitaro. Укажите имя и код страны. Приложение создаёт выключенную кампанию, затем два потока и включает кампанию после успешного создания обоих. Первый поток использует фильтр страны и перенаправляет на Google. Для остальных переходов работает поток офферов.
- **Редактор.** Выберите существующую кампанию с настроенным тестовым префиксом. Офферы можно добавить, убрать или вернуть из архива. Доли активных офферов распределяются целыми процентами до 100% с учётом закреплений. При равном делении остаток раздаётся по одному проценту.
- **Публикация.** Черновик хранится в SQLite и переживает перезапуск. «Опубликовать» отправляет список офферов в Keitaro. «Отменить черновик» возвращает состояние Keitaro. «Обновить» подтягивает внешние изменения. Если Keitaro изменился после начала черновика, публикация остановится с конфликтом.
- **Статистика.** Клики, конверсии, доход, расход и прибыль берутся из отчёта Keitaro за всё время по паре «поток + оффер». При ошибке загрузки статистики редактор остаётся доступен.

## Миграции и сбои

`alembic upgrade head` создаёт или обновляет базу по `DATABASE_URL`. `alembic current` показывает текущую ревизию. Перед откатом миграций сохраните копию SQLite: откат удаляет соответствующие таблицы.

Если Keitaro принял часть запросов создания, приложение возвращает имя и известный ID кампании. Проверьте её в Keitaro перед повтором. Имя резервируется в SQLite перед отправкой первого запроса, чтобы сбой сети не привёл к дубликату.

## Тесты

```sh
pip install pytest
python -m pytest -q
```

Тесты используют временную SQLite и заменяют ответы Keitaro через HTTPX MockTransport.
